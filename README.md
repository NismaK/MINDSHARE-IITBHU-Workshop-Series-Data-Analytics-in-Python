## About the Project

This repository contains a data analytics project developed during the MINDSHARE IIT (BHU) Workshop Series.  
The project focuses on Exploratory Data Analysis (EDA) using Python to understand data patterns, comparisons, and proportions through visualizations.

The objective of this project is to analyze data systematically and extract meaningful insights using appropriate visual representations.

## Visual Representations and Insights

### Bar Graphs

Bar graphs are used to compare values across different categories.  
They help in identifying trends, differences, and dominant categories within the dataset.

### Box Plots

Box plots are used to analyze data spread, median, and variability.  
They also help in identifying outliers and comparing distributions across categories.

### Pie Charts

Pie charts are used to represent proportional distribution of categories.  
They provide a clear understanding of how different parts contribute to the whole.

### Visualization Best Practices

All visualizations are created with proper labels, titles, and consistent formatting to ensure clarity and easy interpretation.
